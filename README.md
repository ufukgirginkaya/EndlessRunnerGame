# 🏃‍♂️ Endless Runner Game in Unity

An endless runner game built with Unity. Dodge falling and ground obstacles while collecting apples and coins to survive longer and increase your score.

![image](https://github.com/user-attachments/assets/140d16f2-af42-4d78-b6fc-1c81bc889a82)

## Gameplay Features
- Continuous forward running with obstacle avoidance
- Obstacles:
  - **Falling objects** from above
  - **Ground obstacle** on the path
  - Hitting obstacles **slows the character down**
- Collectibles:
  - **Coins** increase your score
  - **Apples** increase your speed

## Controls
- **WASD** to move left/right/forward/backward

## Built With
- Unity Engine
- C#
